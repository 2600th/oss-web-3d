# Models polish 2: pilot, truck and the rest of the non-MiG models

Scope: every GLB in `public/models/` except `mig21*.glb` / `mig21_cockpit.glb`.
All models are generated by the scripts in `tools/blender/`; no GLB was edited by hand.

```
blender -b --factory-startup --python tools/blender/build_assets.py -- [ids]
blender -b --factory-startup --python tools/blender/build_pilot.py
node tools/blender/write-catalog.mjs
```

## What changed

Pipeline (`kit.py`, `common.py`, `gltf-pipeline.mjs`, `optimize-glb.mjs`):

- Each model now has three baked maps: base colour, tangent-space normal, ORM. Before there was base colour + ORM only.
- The normal map is baked with a Cycles bevel node, so hard edges read as rounded, plus procedural relief per surface class (paint, metal, rubber, fabric, wood, stone, canvas).
- Albedo post-process in linear light: cavity grime, soft edge lightening, wear to bare metal on exposed edges, ambient occlusion.
- Hidden-face cull before unwrapping and tight UV packing, so texels go to visible surfaces.
- LOD1 drops faces flagged as LOD0-only detail, then decimates to a triangle target; it shares the LOD0 UVs and maps.
- Runtime: `src/assets/materials.js` now layers the ground detail bump on the GLB's normal map instead of replacing it.

## GPU cost

`?mission=m1&quality=high&tod=noon&gputime`, 1600x900, paused, camera held on the M1 ridge strongpoint (AAA gun, sangars, tents in view; see `after-m1-strongpoint-gputime.jpeg`). `window.__perf.profiler.summary()` over 60 frames after the change:

| Pass group | ms |
| --- | ---: |
| scene | 0.262 |
| post | 0.165 |
| clouds | 0.082 |
| other | 0.058 |
| shadow | 0.020 |
| vfx | 0.013 |
| total | 0.600 |

Limits of this reading:

- No "before" reading was taken at this pose, so there is no measured delta. The expected change is one extra texture sample per ground-unit fragment and fewer triangles.
- The page ran at about 10 frames per second in a shared, backgrounded browser, and the absolute figures look low for this pipeline. Treat them as a sanity check that nothing became expensive, not as a benchmark.
- M1 has no convoy at this strongpoint (`systems.ai.convoys` was empty), so the scene is a strongpoint, not a convoy.

## What was verified in game

- Seen in game at close range after the final build: all 12 ground units listed above, the six destroyed variants in the lineup, all nine weapons, helicopter and helipad, pilot in the jet (through the canopy, canopy hidden, cockpit view) and standalone.
- LOD1 seen in game for truck, AAA gun and SAM launcher only. Other LOD1 files were not looked at; the catalogue test confirms each is lighter than LOD0.
- Node names, checked by script from the GLB JSON: every file has the same node-name set as the GLB it replaces, and each LOD1 the same as its LOD0. Turret, barrel, launcher and dish nodes have identical translations in LOD0 and LOD1. Static mesh-carrying nodes (`body`, `hull`, `carriage`, `structure`, ...) differ between LODs by up to a few centimetres in their stored translation: that is the meshopt quantisation offset of the mesh, not a moved pivot. The helicopter `rotor` node differs by 8 mm in height between LODs.
- Cockpit view: `pilot_head` is hidden and still turns (`rotation.y` changed with the look direction); body, gloves on stick and throttle, and legs are visible.
- No console errors or warnings on the M1 page.
- Not verified: night and storm lighting, the WebGL2 fallback, low and medium quality tiers, hostile jets carrying `pilot_lod1`, the destroyed swap during a real strike, and the other agent's distance-LOD switch.
- `npm test` (249 pass) and `npm run build` pass.
